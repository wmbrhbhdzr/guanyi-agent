# 观弈（GuanYi）

基于视觉语言模型的离散决策游戏智能体。

> **当前状态**：仅完成开发环境配置与项目文档骨架，仓库中尚无任何可运行代码；本 README 只描述已存在的文件和已确定的设计约束，尚未实现的功能一律标注为“未实现”。

## 1. 项目背景

本项目为《软件应用开发实践》课程个人项目，同时作为毕业设计的前期预研。目标是让视觉语言模型（VLM）在**只观察屏幕像素**的条件下完成游戏决策，并通过结构化记忆机制在多次对局中持续改进表现。

## 2. 设计约束（已确定）

- **像素优先**：决策层输入只有屏幕截图，不读取内存、存档、日志或 Mod 接口等游戏内部数据。
- **真值隔离**：游戏内部状态仅用于离线评测、日志标注与动作合法性校验，不进入模型上下文。
- **决策点采样**：不逐帧分析画面，仅在需要决策时采集截图，以控制延迟与调用成本。

计划流程：`截取屏幕 → VLM 视觉理解 → 结构化动作 → 执行 → 记录 → 评测 → 记忆更新 → 循环`，该流程中的每一个环节目前均未实现。

## 5. 模型说明

运行时决策模型调用名为 `deepseek-flash`。旧名称 `deepseek-v4-flash` / `deepseek-v4-flash-vision-exp` 为别名，实际由 DeepSeek-V4.1-Flash 提供服务，按 Flash 价格计费。
