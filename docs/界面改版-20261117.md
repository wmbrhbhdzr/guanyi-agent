# 界面改版记录（2026-11-17）

阅读实验8要求后，本轮先调整界面，暂不开展实验8的系统集成和报告撰写。

## 两项问题的处理范围

- 画面采集与操作分析仍是两个独立入口。这项连接已经在原核心用户流程和FR-02/04/05中规划，
  实验7先实现视觉原型，实验8第2.1、2.2要求把原型接入原软件的界面、业务与数据层。
  后续集成应完成“窗口画面 → 局面检查/编辑 → 建议与依据 → 实际操作记录 → 复盘”，
  统一多敌人、卡牌费用、未知字段、任务编号与来源；不能直接把识别JSON塞入旧单敌人表单并沿用默认值。
- 现有页面只实现了基本入口，没有统一的视觉主题。本轮独立补齐主题与排版，不修改AI或业务数据流程。

## 界面改动

- 暖白背景、深灰文字、苔绿主按钮和陶土色提示；蓝色不再作为主色。
- 新增品牌区、页面标题和简短操作说明，统一按钮、输入框、页签、列表和文本区样式。
- 默认打开“游戏画面识别”；窗口来源、采集控制、当前画面和结果分层显示。
- “核心任务页”展示名称调整为“决策记录”，整理局面、规则建议、实际操作三栏。
- 所有Tk/ttk主题集中在`guanyi/ui/theme.py`，不增加第三方UI依赖。
- 字号以像素定义，避免高DPI环境中标题与控件异常膨胀；旧功能、事件与测试注入接口保留。

## 验证

114个原有测试通过；六页界面冒烟检查原有录入、问答、Agent、图像识别操作。
窗口采集和连续控制仍使用现有测试验证。本轮没有重跑收费模型或修改实验7固定评测结果。
另在1280×900的本机窗口检查画面识别和决策记录页，确认主要按钮与三栏内容正常显示。
排版预览保存在忽略目录`runs/ui_refresh/`，显示的是固定样例示例内容，不是新一次真实模型结果。
