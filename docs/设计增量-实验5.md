"""实验5 §2.6：知识问答模块的设计增量说明。

实验3 的架构基线（分层 + 端口适配器）保持不变；实验5 在**不改动 core** 的前提下，
新增了一个可替换的能力端口与一组适配实现，用于回答“为什么这样打更好”。

## 一、新增能力：知识检索（端口 I-9）

| 项 | 内容 |
| --- | --- |
| 端口 | **I-9 知识检索**：`search(question, top_k) -> [{chunk, score, source}]` |
| 为什么是端口 | 检索方式（关键词／向量／混合）与知识来源（本地文件／远程接口）都可能替换，与实验3 对 I-2（模型决策）的处理方式一致 |
| 实现（实验5） | `guanyi/knowledge/retriever.py`：BM25 简化 + 词频向量余弦 + 同义词归一，混合排序 |
| 知识来源 | `knowledge/*.md`（由 `scripts/build_kb.py` 从 STS2 社区数据接口生成，见 `knowledge/SOURCES.md`） |

## 二、新增模块与职责

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| `guanyi/knowledge/splitter.py` | 加载知识库、按 `## ` 标题切片段、片段元数据与规模统计 | 无（标准库） |
| `guanyi/knowledge/retriever.py` | 混合检索、Top-k、排序依据、资料不足判定 | splitter |
| `guanyi/ai/llm_client.py` | 文本 chat/completion 调用：`.env` 密钥、超时、重试、失败返回、费用折算 | 标准库 |
| `guanyi/ai/prompts.py` | Prompt 模板（直接组 / RAG v1 / RAG v2）、上下文拼装、多轮历史 | 无 |
| `guanyi/app/qa_service.py` | 用例编排：问题 → 检索 → 上下文 → 调用 → 带出处回答；落盘完整记录 | 以上三者 |
| `guanyi/cli.py` 新增 `kb` / `ask` / `context` | 检索预览 / 问答 / 展示实际发送的完整输入 | qa_service |
| `guanyi/ui/main_window.py` 新增「答疑」页 | 问题输入 → 回答与出处展示 | qa_service |

## 三、数据流

```
玩家问题
  → (I-9) 检索：knowledge/*.md 的 53 个片段 → Top-3（BM25 + 词频余弦）
  → 上下文组织：片段编号 [来源1..3] + 问题 → Prompt v2（系统规则 + 用户消息）
  → (I-2 的文本形态) 云端模型调用：deepseek-flash
  → 回答（含 [来源N] 引用）+ 出处列表
  → 落盘：data/qa/qa_<时间戳>.json（检索片段、实际上下文、回答、耗时、用量、费用）
```

## 四、与“真值隔离”边界的关系（关键设计约束）

本项目的核心约束是**决策模型不能读取游戏内部数据**，只能看画面。实验5 新增的知识检索
**不改变这条边界**，理由：

1. 知识库只存放**通用游戏知识**（卡牌数值、状态机制、敌人行动、遗物效果），
   **不含当前局面、玩家血量、敌人意图实例等对局数据**；
2. 知识检索服务于**解释层**（回答“为什么”），不参与决策层（决策仍是“截图 → 模型”）；
3. 调用模型时只发送“用户问题 + 检索到的知识片段”，不发送截图、对局记录或账号信息；
4. 以后若要把知识用于决策提示，也必须走“模型看图 → 模型决策 → 知识库补充依据”的顺序，
   而不是把对局数据塞进上下文。

## 五、验收条件（对照实验2 用户故事）

| 用户故事 | 本实验的满足方式 |
| --- | --- |
| US-01 每个决策点看到建议与理由，理解“为什么这样打更好” | 答疑模块可解释卡牌/状态/敌人行为，回答带来源引用 |
| US-06 在固定问题集上对比不同方案并量化 | 7 个固定问题 × 直接组/RAG 组对照，记录正确性、耗时、token、费用 |

## 六、风险与局限

- **知识时效**：知识库由脚本抓取生成，游戏版本更新后需重跑 `scripts/build_kb.py`；
- **检索能力**：本机不便安装分词与嵌入模型，采用“同义词 + 2-gram + BM25 + 词频余弦”，
  对口语化改写的召回仍有上限（如“怎么打才不掉血”这类说法）；
- **引用可靠性**：目前靠 Prompt 约束 + 自动检查引用编号有效性，尚未做到逐句引文核验；
- **成本**：单次问答约 0.002 元，对照实验一次约 0.03 元，仍远低于实验1 实测的视觉决策成本。
