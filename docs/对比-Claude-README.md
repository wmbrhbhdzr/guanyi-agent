# 观弈（GuanYi）

基于视觉语言模型的离散决策游戏智能体。

> README 草案（Claude Code 生成），用于与 DSH 输出对比。内容严格对应仓库现状：**当前尚无源代码**。

## 项目背景

《软件应用开发实践》课程个人项目，兼作毕业设计前期预研。
目标是让视觉语言模型（VLM）在只观察屏幕像素的条件下完成游戏决策，
并通过结构化记忆机制在多次对局中持续改进表现。

## 核心设计约束

- **像素优先**：决策层输入只有屏幕截图，不读取任何游戏内部数据
  （内存、存档、日志、Mod 接口），以保证方案通用而非只适配单一游戏。
- **真值隔离**：游戏内部状态仅用于离线评测、日志标注与动作合法性校验，
  绝不进入模型上下文，也绝不作为动作执行通道。
- **决策点采样**：不逐帧分析画面，仅在需要决策时采集截图，控制延迟与调用成本。

## 核心流程（设计目标，未实现）

```
截取屏幕 → VLM 视觉理解 → 结构化动作 → 执行 → 记录 → 评测 → 记忆更新 → 循环
```
